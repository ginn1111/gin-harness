Does the C2C state model feel right?PROTOTYPE

C2C runs two state layers that must stay in step: the wire states ChatGPT sees (INIT / PLAN / EXECUTED / DONE … typed into the web UI) and the local checkpoint the agent resumes from after a crash or a lost chat. This demo pushes both through the awkward cases — restart while waiting for review, lost chat mid-loop, iteration cap, attempts to invent a STATE: RESUME — so you can feel whether the model holds or leaks.
