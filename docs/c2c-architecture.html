C2C Core Module Architecture

core/c2c — ChatGPT plans, the local executor works. Read-only MCP data plane + tiny [C2C] control plane.

Data plane vs control plane

  • • MCP = data plane: ChatGPT pulls files/diffs/search itself
  • • [C2C] messages = control plane, always < 1 KB
  • • Never paste file bodies, diffs, or logs into chat
  • • No write/exec MCP tools exist in V1

Security model

  • • Loopback-only listener, port fallback via /health probe
  • • OAuth 2.1: DCR + authorization code + PKCE S256
  • • Pairing code: CSPRNG, TTL, attempt + IP rate limits
  • • Workspace path containment + .c2cignore + sensitive-file policy

src/ modules

  • • bridge/ mcp/ auth/ pairing/ — server, tools, OAuth, codes
  • • workspace/ — containment, ignore rules, search, git views
  • • tunnel/ process/ execution/ — edge, daemon, JSONL records
  • • cli/ config/ logger/ — c2c commands, state dir, redaction
