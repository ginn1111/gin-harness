# Choose the canonical source for work size and rationale

## Question

Where must explicit work size (`XS`, `S`, `M`, `L/XL`, or risky condition) and its concise rationale be recorded so that Ginflow routing can consume it deterministically without guessing from free-form task text?

The decision must compare structured card metadata, linked Brief/Plan headings, and shaping-context-only representation. It must preserve Kanban as lifecycle authority, keep the card thin, support restartability, and define behavior when the value is absent or malformed.
